# سينمانا نكست — CinemaNa Next (عميل سطح مكتب + أداة اختبار)

مشروع للوصول إلى خدمة **سينمانا** التابعة لمزود الخدمة (Earthlink / Shabakaty)
من تطبيق سطح مكتب سريع بواجهة شبيهة بنتفليكس، مع أداة سطر أوامر لاختبار
نقاط الاتصال (بُنيت أولاً وأبقت كأداة تشخيص).

- **المرحلة 1 — `cinemana-probe`**: أداة CLI بلغة Go لاختبار نقاط النهاية.
- **المرحلة 2 — `desktop/`**: تطبيق سطح مكتب (Wails v2 + Vue 3 + Tailwind v4)
  باسم **سينمانا نكست / CinemaNa Next** (الناتج: `CinemaNaNext.exe`).
- **`core/cinemana/`**: نواة API المشتركة بينهما (فصل منطق الشبكة عن العرض).

الأداة تعالج من البداية المشاكل التي دفعت لبناء المشروع:

| المشكلة في المتصفح | الحل في المشروع |
|---|---|
| حجب CORS | لا يوجد CORS أصلاً خارج المتصفح؛ وللمشغل المدمج وكيل بث محلي |
| Secure DNS الخارجي (DoH) يفشل في حل نطاقات المزود | DNS محلي عادي عبر البورت 53 (محلل النظام افتراضياً، أو خادم مفروض بـ `--dns`) |
| البروكسي/VPN يعترض الاتصال بالشبكة المحلية | `Proxy: nil` — تجاهل كامل لأي إعداد بروكسي في النظام |
| قيود مشغلات الويب | مشغل مدمج (HTML5/hls.js عبر وكيل بث) + زر فتح في mpv الخارجي |
| التمييز عن زوار الويب | ترويسات تحاكي تطبيق الأندرويد الرسمي (Dalvik UA + `X-Requested-With`) في كل الطلبات وبث الفيديو |

## المرحلة 2 — تطبيق سطح المكتب (`desktop/`)

تطبيق Wails v2 (الواجهة تعمل في WebView2 المدمج بويندوز — خفيف بلا نواة
كروم مكررة كما في Electron)، واجهة Vue 3 + Tailwind v4 عربية RTL بوضع داكن.

```bash
cd desktop
wails build          # ينتج build/bin/Cinemana.exe (ملف واحد شامل الواجهة)
wails dev            # تطوير حي (اختياري)
```

الميزات:
- **الصفحة الرئيسية**: قسم "الأعلى تقييماً Top" بتبويبات (أفلام/مسلسلات/أنمي)
  وبطاقات مرقمة، ثم صفوف أفقية (أحدث الأفلام الأجنبية / المسلسلات الأجنبية /
  أفلام الأنمي / مسلسلات الأنمي / الأفلام العربية / المسلسلات العربية /
  أحدث الإضافات) — تُجلب الصفوف كسولاً عند اقتراب ظهورها.
- **لوحة الفلترة (يمين النافذة)**: بحث نصي + النوع + اللغة (عربي/أجنبي) +
  التصنيف + أدنى تقييم + نطاق السنة — عبر فلاتر AdvancedSearch الفعلية
  (`star`, `year=من,إلى`, `category_id`) و`videosByCategoryAndLanguage` للغة.
- **الشريط الجانبي (يسار النافذة)**: المفضلة، المشاهدات الأخيرة، وقوائم
  خاصة ينشئها المستخدم ويضيف إليها الأعمال (تُحفظ محلياً بين الجلسات).
- **صفحات "المزيد"**: كل صف في الرئيسية له زر "المزيد" يفتح شبكة كاملة
  للصنف (حتى 60 عملاً عبر ترقيم صفحات تلقائي) مع فرز: الأعلى تقييماً / الأحدث.
- **نسخ احتياطي**: تصدير المفضلة والقوائم والمشاهدات إلى ملف JSON
  (حوار حفظ) واستيراده مع دمجه بالبيانات الحالية — من نافذة الإعدادات.
- **دمج المحتوى المكرر**: الخدمة تحتفظ بنسخ متعددة لنفس العمل (بعضها
  ملفاتها ميتة) — العرض يدمجها ويحفظ البدائل في حقل `alts`، وعند فشل
  تشغيل النسخة الأساسي يجرب البدائل تلقائياً في `GetPlayback`.
- **تخطيط بعرض كامل**: لا سقف للعرض — الشبكات تتمدد بعدد أعمدة تلقائي
  حسب حجم النافذة (ملء الشاشة يستغل كل المساحة).
- **حجم بطاقات البوسترات**: إعداد في نافذة الإعدادات (صغير/متوسط/كبير/
  ضخم) يتحكم عبر متغير CSS `--card-w` في كل الشبكات والصفوف فوراً.
- بحث فوري (debounce) مع مرشح نوع وشبكة بوسترات بدقة كاملة.
- صفحة تفاصيل: وصف/سنة/تقييم/تصنيفات + زرا المفضلة و"إضافة إلى قائمة"،
  مواسم وحلقات للمسلسلات، شرائح الجودات، اختيار الترجمة، وزر تشغيل بارز.
- **استئناف المشاهدة**: موضع التوقف يُحفظ كل 5 ثوانٍ (localStorage بمفتاح
  معرف الفيلم/الحلقة) ويُستأنف تلقائياً عند العودة — ويُمسح عند انتهاء العمل
  أو الضغط على "من البداية".
- **تنسيق الترجمة**: الترجمة تُرسم كطبقة خاصة فوق الفيديو (لا عبر ::cue
  المقيّد) — لوحة (زر "الترجمة") لتحديد الخط والحجم ببكسل حقيقي ولون
  النص ولون الخلفية وشفافيتها مع معاينة حية، وتُحفظ محلياً. **خطوط عربية
  مدمجة محلياً تعمل بلا إنترنت**: Cairo، Tajawal، Almarai، Noto Kufi،
  Amiri، Aref Ruqaa، Lalezar (المجلد `assets/fonts/`، ترخيص OFL).
  وسوم ASS الموروثة مثل `{\an8}` تُزال تلقائياً من نص الترجمة.
- مشغل مدمج بملء الشاشة: mp4 مباشرة، وHLS عبر hls.js — كل الطلبات تمر
  عبر **وكيل البث المحلي** (proxy.go على 127.0.0.1) يضيف ترويسات المحاكاة
  ويمرر رأس Range (بحث/تقديم يعملان) ويعيد كتابة قوائم m3u8 ويحوّل
  الترجمات SRT→VTT (مع دعم ترميز windows-1256 العربي). الترجمة تُحقن في
  المشغل كـ Blob URL فيتجاوز أي قيود CORS، مع زر CC للإظهار/الإخفاء.
- زر "فتح في مشغل MPV": يمرر الرابط الموقّع مباشرة مع
  `--user-agent` و`--http-header-fields` وملف الترجمة — ضغطة واحدة
  (يتطلب mpv: `winget install mpv`، أو حدد مساره من الإعدادات).
- إعدادات محفوظة في `%APPDATA%\cinemana-desktop\config.json`.

### ملاحظة بيئية مؤكدة بالفحص

عقد فيديو المزود (`cdn/cndw*.shabakaty.cc`) تعيد 503 من **خارج** شبكة
المزود — التشغيل الفعلي يتطلب الاتصال بشبكة Earthlink (واجهات الـ API
والترجمات تعمل من أي مكان). اختبارات الشبكة في `desktop/proxy_test.go`
تتخطى هذه الحالة تلقائياً؛ شغّلها بالكامل من داخل الشبكة:
`CINEMANA_LIVE=1 go test ./desktop/`.

### نقاط الاستعراض (مستخرجة من تطبيق الويب الرسمي للخدمة)

| الوظيفة | المسار (على `cinemana.shabakaty.cc/api/android/`) |
|---|---|
| أحدث الأفلام / المسلسلات | `latestMovies` / `latestSeries` + `level/3/itemsPerPage/48/page/N` |
| الأعلى تقييماً | `videosByCategory?categoryID=56&orderby=DESCENDINGIMDBRATE&videoKind=1\|2` |
| الأنمي (رسوم متحركة) | التصنيف `57` عبر `videosByCategory` |
| فلترة باللغة | حقل `language_lighttigerNb` في العناصر: `7` أجنبي، `9` عربي |
| تصنيفات الخدمة | `mainCategories?lang=ar` |

تفاصيل التنفيذ والصيغ (مصفوفة أو `{"info":[...]}`) موثقة في
`core/cinemana/browse.go`، ويمكن تجربتها من الـ CLI:
`cinemana-probe collection top_movies` أو `latest_movies_arabic` أو `top_anime`.

## بناء الأداة (المرحلة 1)

```bash
go build -o cinemana-probe.exe .
```

(يوجد ملف `cinemana-probe.exe` جاهز؛ أعد البناء بعد أي تعديل.
الاختبارات: `go test ./...` — تعمل بلا شبكة.)

## الأوامر

```bash
cinemana-probe probe                              # فحص شامل: DNS + الوصول + التحويل + نقاط النهاية
cinemana-probe search "fast and furious" --type movie
cinemana-probe details 5386                       # تفاصيل فيلم (عنوان/بوستر/وصف/سنة/ترجمات)
cinemana-probe videos 5386                        # روابط الفيديو بجوداتها + الترجمات
cinemana-probe seasons 653                        # مواسم مسلسل وحلقاته
cinemana-probe all "game of thrones" --type series  # السلسلة كاملة لأول نتيجة (--index i لاختيار غير الأول)
```

الأعلام يمكن كتابتها قبل المعاملات أو بعدها (إعادة ترتيب تلقائية).
كل المخرجات JSON منسق بمسافات بادئة، والنصوص العربية تُطبع كما هي (UTF-8).
رموز الخروج: `0` نجاح، `1` خطأ، `2` خطأ استخدام.

### الخيارات المشتركة

| الراية | الوظيفة |
|---|---|
| `--base-url URL` | العنوان الأساسي (افتراضياً `https://cinemana.shabakaty.com`) |
| `--dns 10.0.0.1` | فرض خادم DNS محلي محدد (DNS عادي 53 — مفيد إذا كان النطاق محسوماً فقط على DNS المزود) |
| `--resolve host=ip` | تثبيت نطاق على IP مباشرة (مثل `--resolve cdn.shabakaty.cc=10.10.0.5`)، يُكرر أو يُفصل بفواصل |
| `--ua "..."` | User-Agent بديل |
| `--app-id pkg` | قيمة `X-Requested-With` (افتراضي `com.erthlink.tv`، اتركه فارغاً لإلغائه) |
| `--timeout 20s` | مهلة الطلب الواحد |
| `--insecure` | تخطي التحقق من شهادة TLS (للاختبار داخل الشبكة المحلية فقط) |
| `--type movie\|series\|all` | نوع البحث (افتراضي `all`) |
| `--page N` | صفحة نتائج البحث |
| `--no-hls-parse` | عدم جلب/تحليل قوائم m3u8 (تسريع عند بطء الشبكة) |

## ملاحظات مهمة اكتشفها الفحص الفعلي

1. **إعادة توجيه النطاق:** `cinemana.shabakaty.com` يعيد `302` إلى
   `cinemana.shabakaty.cc`. الأداة تحتفظ بـ `.com` كعنوان أساسي وتتبع
   التحويل تلقائياً (تظهر الوجهة النهائية في `request.final_url`).
2. **روابط موقعة مؤقتة:** روابط الفيديو/الصور/الترجمات تحمل
   `AWSAccessKeyId` و`Expires` و`Signature` (تخزين بأسلوب S3)، وحقل
   `objectUrlExpiration` يوضح تاريخ الانتهاء. **لا تخزن هذه الروابط
   طويلاً في التطبيق المستقبلي** — اطلبها قبل كل تشغيل.
3. **إلىن DNS المحلل النقي في Go:** عند فرض `--dns` يستخدم Go محللاً
   "نقياً" يرسل استعلامي A وAAAA معاً؛ بعض راوترات المزودين تجيب
   NXDOMAIN لهذا النمط فتفشل عملية الحل رغم وجود النطاق (لوحظ
   متقطعاً أثناء التطوير). لهذا الافتراضي هو محلل نظام التشغيل، وهو
   نفس سلوك أي تطبيق سطح مكتب. في كل الأحوال **لا DoH إطلاقاً**.
4. **الجودات:** الخدمة تعيد حالياً ملفات MP4 مباشرة بمستويات
   240p/360p/480p/720p/1080p على نطاق `cdn.shabakaty.cc`. كود تحليل
   قوائم HLS (`m3u8`) موجود وجاهز لإن ظهرت (مغطى باختبارات وحدة).
5. **المسلسلات:** نقطة `videoSeason` تعيد كل الحلقات دفعة واحدة مع
   `season` و`episodeNummer`، ولكل حلقة `nb` خاص يُستخدم مع
   `transcoddedFiles` و`allVideoInfo`.

## مرجع نقاط النهاية (مستخرج من الفحص الفعلي)

| الوظيفة | المسار |
|---|---|
| البحث | `GET /api/android/AdvancedSearch?videoTitle=<q>&type=movie\|series&page=<n>` |
| تفاصيل العمل | `GET /api/android/allVideoInfo/id/<nb>` |
| ملفات الفيديو بجوداتها | `GET /api/android/transcoddedFiles/id/<nb>` |
| حلقات المسلسل | `GET /api/android/videoSeason/id/<nb المسلسل>` |

المعرّف `nb` يأتي من نتائج البحث. حقول مهمة في الردود:
`en_title`/`ar_title`، `year`، `stars` (تقييم)، `kind` (`1` فيلم، `2` مسلسل)،
`imgObjUrl` (بوستر)، `en_content`/`ar_content` (وصف)،
`translations` (ترجمات باسم لغة وامتداد ورابط)،
`resolution` + `videoUrl` (جودة الفيديو)، `season` + `episodeNummer` + `nb` (حلقة).

## بنية الكود (للصيانة والتعديل)

| المسار | الدور |
|---|---|
| `core/cinemana/client.go` | عميل HTTP المشترك: تجاوز البروكسي، DNS المحلي/المفروض، تثبيت النطاقات، ترويسات الأندرويد |
| `core/cinemana/api.go` | نقاط النهاية + البنى الخام المطابقة لردود الخدمة حرفياً |
| `core/cinemana/media.go` | تطبيع المخرجات، تمييز أنواع الروابط، محلل HLS، استخراج الترجمات |
| `main.go` | أداة CLI (المرحلة 1): الأوامر، غلاف JSON، أمر الفحص الشامل |
| `core/cinemana/media_test.go` | اختبارات وحدة للمحلل والدوال الحساسة (بلا شبكة) |
| `desktop/main.go` | نقطة دخول Wails: النافذة وتضمين أصول الواجهة |
| `desktop/app.go` | طبقة الربط: الدوال المنسوجة للواجهة (Search/GetPlayback/OpenInMPV...) |
| `desktop/proxy.go` | وكيل البث المحلي: ترويسات + Range + إعادة كتابة m3u8 + SRT→VTT |
| `desktop/settings.go` | الإعدادات المحفوظة (مسار mpv، العنوان الأساسي، UA) |
| `desktop/frontend/src/` | واجهة Vue 3: مكونات الشبكة/التفاصيل/المشغل + طبقة `services/api.js` |
| `desktop/frontend/src/services/mock.js` | بيانات تجريبية لمعاينة الواجهة في متصفح عادي بلا تطبيق |
| `desktop/frontend/src/assets/fonts/` | خطوط عربية مدمجة (Cairo، Amiri...) — تُحدَّث بـ `desktop/download_fonts.py` |
| `desktop/icons/` + `desktop/update-icon.ps1` | أيقونة التطبيق: ضع `icon.ico` هنا ثم شغّل السكربت وأعد البناء |

قاعدة الفصل المعماري: `core/cinemana` لا يعرف شيئاً عن الواجهات،
`desktop/frontend` لا يستدعي الشبكة إلا عبر `services/api.js`.
