# مجلد الأيقونة — CinemaNa Next

ضع أيقونة التطبيق هنا بأحد الصيغين (أو كليهما):

| الملف | الوظيفة |
|---|---|
| `icon.ico` | أيقونة ملف `CinemaNaNext.exe` وشريط مهام ويندوز (موصى به — متعدد الأحجام 16/32/48/256) |
| `icon.png` | أيقونة PNG مربعة (512×512 أو أكبر) — تُستخدم كمصدر بديل |

## طريقة التطبيق

بعد وضع الأيقونة في هذا المجلد، شغّل من مجلد `desktop`:

```powershell
powershell -ExecutionPolicy Bypass -File update-icon.ps1
```

السكربت ينسخ الأيقونة إلى مكان البناء الصحيح (`build/windows/icon.ico`
و/أو `build/appicon.png`)، ثم أعد البناء:

```powershell
wails build
```

ستظهر الأيقونة الجديدة على ملف الـ exe وفي شريط المهام وعنوان النافذة.
